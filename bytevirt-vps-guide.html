常见问题

洛杉矶有四档大陆优化线路，怎么选？
按「预算 → 线路等级」排：Premium（4837）最便宜、口子大流量多，适合业务拼车；Signature（4837，圣何塞）是「平衡档」，用 Premium 的价格给 Elite 级别的流量；Elite（9929 + CMIN2）是主力档，电联 9929、移动 CMIN2，三网都照顾到；CN2 GIA路由等级最高（上游 DMIT），但口子最小、价格最贵。
哪款最适合中国电信用户？
洛杉矶 CN2 GIA。它是全系里唯一走电信 CN2 GIA 的线路，NodeSeek 有帖主直接评价「看起来是电信爽鸡」。次选洛杉矶 Elite（电信走 9929）。
哪款最适合中国联通用户？
洛杉矶 Elite。IPv4 走 9929、IPv6 三网 CMIN2，联通口碑最好。要避开东京大陆优化——社区反馈「联通依旧延迟炸飞了」。
哪款最适合中国移动用户？
选择最多：东京 / 新加坡大陆优化被社区称为「移动快乐机」；洛杉矶 Elite 走 CMIN2（移动专属）；NAT 产品的新加坡 / 台湾节点也是「移动快乐鸡」。
需要干净的 IP 跑 ChatGPT、Claude 等 AI 服务，选哪款？
优先原生 ISP 系列（东京 ISP / 香港 ISP / 台湾 ISP）。但要注意两点：一是这些多为「伪家宽」，二是社区反馈 IIJ 段（东京 ISP）在 Google 侧送中比例较高。另外新加坡大陆优化有评论指出「IP 不算太干净，跑 AI 建议再套落地机」。
超低价入门选哪款？
NAT 共享 IP · LXC，最低 $7.7 / 年（约合每月 $0.64）。注意 NAT 产品没有独立 IPv4，只有约 20 个转发端口 + 独立 IPv6，且官网明说 IPv4 默认被 GFW 屏蔽，建议走 IPv6。
流量用完了会怎样？
端口降到 1 Mbps，服务器不会停机。大部分套餐可以单独购买额外流量，也可以开自动续流量。
支持哪些支付方式？
支付宝（人民币）、银联 / 云闪付、USDT（TRC20）。
开机会等多久？
付款后自动开通，通常约一分钟。
ByteVirt 和 wap.ac 是什么关系？
社区讨论（NS924794）指出有用户从 wap.ac 的 HiNet 机器登录 SSH 时看到 Thanks for using ByteVirt!，说明两家共用同一套后端 / 镜像。评论区也有人用「上游 / 下游」来描述。
ByteVirt 有哪些已知风险？
三点：① 2026-07 遭遇过大规模 DDoS，官方 TG 群一度解散（NS810717）；② 低配机型内存太小，有用户反馈「挂个探针过几天就会失联，必须进控制台手动重启」（NS849431）；③ IP 数据库归属地偶发异常，有帖主反馈「IP 被送港」（NS943962）。建议不要把它当唯一的生产环境。

选购注意事项

1. 价格与库存是抓取时点快照，随时会变（ByteVirt 调价、补货都比较频繁）。下单前以官网实时信息为准。
2. 「大陆优化」不等于三网都优化。东京大陆优化走的是软银 + IIJ 混合，对移动友好、对联通不友好； > 新加坡大陆优化也是移动优先。买之前先确认自己是什么运营商。
3. NAT 产品的 IPv4 默认被 GFW 屏蔽，官方建议走 IPv6。特殊地区（巴基斯坦 / 埃及 / 尼日利亚 / 荷兰 / 乌克兰 / 意大利）不支持退款。
4. 低配机型容易内存不足。多篇帖子提到小内存档位跑个测速就会离线、探针会失联。买之前把内存留够余量。
5. 「伪家宽」不是真家宽。ISP 系列卖的是 IP 属性，线路质量另说；社区也提醒不要指望买到便宜的香港静态家宽。
